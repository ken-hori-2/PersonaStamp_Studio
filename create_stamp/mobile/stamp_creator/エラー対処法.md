# エラー対処法

## 🔴 発生したエラー

```
処理中にエラーが発生しました: The operation couldn't be completed. (Foundation._GenericObjCError error 0.)
```

## 🔍 エラーの原因

### 主な原因

1. **人物が写っていない画像を使用している**
   - Vision Frameworkの人物セグメンテーション（`VNGeneratePersonSegmentationRequest`）は、**人物が写っている画像でのみ動作**します
   - 滝、風景、物体だけの写真では動作しません

2. **画像の形式やサイズの問題**
   - 極端に大きい/小さい画像
   - 対応していない画像形式

3. **画像の向きの問題**
   - EXIF情報による画像の向きが正しく処理されていない場合

## ✅ 解決方法

### 1. 人物が写っている画像を使用する

**推奨画像:**
- ✅ 人物がはっきり写っている写真
- ✅ 人物が画面の中央付近に写っている写真
- ✅ 背景と人物のコントラストがはっきりしている写真
- ✅ 明るく、鮮明な写真

**非推奨画像:**
- ❌ 人物が写っていない写真（風景、物体のみ）
- ❌ 人物が非常に小さい写真
- ❌ 人物がぼやけている写真
- ❌ 極端に暗い/明るい写真

### 2. 改善されたエラーメッセージ

コードを改善したため、今後はより分かりやすいエラーメッセージが表示されます：

- **人物が検出されない場合:**
  ```
  人物が検出されませんでした。
  
  このアプリは人物が写っている画像でのみ動作します。
  人物がはっきり写っている写真を選んでください。
  ```

- **画像処理エラーの場合:**
  ```
  画像処理に失敗しました。人物が写っている画像を選んでください。
  ```

### 3. UIの改善

アプリの上部に注意書きを追加しました：
- ⚠️ **「人物が写っている画像が必要です」** という表示が常に表示されます

## 🔧 実装した改善点

### 1. エラーハンドリングの改善

- より詳細なエラーメッセージ
- エラーの種類に応じた適切なメッセージ表示
- 画像変換方法の改善（CIImageを直接使用）

### 2. UIの改善

- アプリ上部に注意書きを追加
- エラーメッセージをより分かりやすく

## 📝 テスト手順

1. **人物が写っている画像でテスト**
   - カメラで人物を撮影
   - または、フォトライブラリから人物が写っている写真を選択
   - 「背景を除去」ボタンをタップ
   - ✅ 正常に動作するはずです

2. **人物が写っていない画像でテスト**
   - 風景写真などを選択
   - 「背景を除去」ボタンをタップ
   - ⚠️ 「人物が検出されませんでした」というメッセージが表示されます

## 🚀 今後の拡張案

人物以外の被写体にも対応したい場合は、CoreMLモデルを追加する必要があります：

1. **U^2Net** - 汎用的な背景除去モデル
2. **MODNet** - より高精度な人物背景除去
3. **DeepLabV3** - 複数の物体カテゴリに対応

詳細は `CoreMLモデルについて.md` を参照してください。
