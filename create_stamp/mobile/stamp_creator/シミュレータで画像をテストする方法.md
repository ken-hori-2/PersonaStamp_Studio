# シミュレータで画像をテストする方法

シミュレータではカメラ機能は使用できませんが、フォトライブラリから画像を選択してテストできます。

## 📸 方法1: ドラッグ&ドロップ（最も簡単）

### 手順

1. **シミュレータを起動**
   - Xcodeでアプリを実行してシミュレータを起動

2. **フォトアプリを開く**
   - シミュレータのホーム画面で「写真」アプリを開く
   - または、アプリ内の「写真を選ぶ」ボタンから直接選択

3. **画像をドラッグ&ドロップ**
   - MacのFinderで画像ファイル（.jpg, .pngなど）を開く
   - 画像をシミュレータのフォトアプリに**ドラッグ&ドロップ**
   - 画像が自動的にフォトライブラリに追加されます

4. **アプリで使用**
   - アプリに戻り、「写真を選ぶ」ボタンをタップ
   - 追加した画像を選択

### 対応画像形式
- ✅ JPEG (.jpg, .jpeg)
- ✅ PNG (.png)
- ✅ HEIC (.heic)
- ✅ その他、iOSがサポートする画像形式

## 🌐 方法2: Safariで画像を保存

### 手順

1. **シミュレータでSafariを開く**
   - シミュレータのホーム画面で「Safari」アプリを開く

2. **画像を検索またはURLを開く**
   - Google画像検索などで人物が写っている画像を検索
   - または、画像のURLを直接入力

3. **画像を長押しして保存**
   - 画像を長押し（右クリック）
   - 「画像を保存」を選択
   - フォトライブラリに保存されます

4. **アプリで使用**
   - アプリに戻り、「写真を選ぶ」ボタンをタップ
   - 保存した画像を選択

---

## 📁 方法3: コマンドラインで画像を追加（最も確実）

### 手順（詳しく）

1. **シミュレータを起動**
   - Xcodeでアプリを実行してシミュレータを起動しておく

2. **ターミナルを開く**
   - `Cmd + Space` でSpotlightを開く
   - 「ターミナル」または「Terminal」と入力してEnter

3. **画像ファイルのパスを確認**
   - Finderで画像ファイルを右クリック
   - `Option` キーを押しながら「パス名をコピー」を選択
   - または、画像をFinderで選択して `Cmd + Option + C` でパスをコピー

4. **コマンドを実行**
   ```bash
   # 基本的なコマンド（画像のパスを指定）
   xcrun simctl addphoto booted /Users/ken/Desktop/my_photo.jpg
   
   # または、ホームディレクトリから相対パスで指定
   xcrun simctl addphoto booted ~/Desktop/my_photo.jpg
   ```

5. **確認**
   - シミュレータで「写真」アプリを開く
   - 追加した画像が表示されているか確認

6. **アプリで使用**
   - アプリに戻り、「写真を選ぶ」ボタンをタップ
   - 追加した画像を選択

### 実践例

```bash
# 例1: デスクトップの画像を追加
xcrun simctl addphoto booted ~/Desktop/person_photo.jpg

# 例2: ダウンロードフォルダの画像を追加
xcrun simctl addphoto booted ~/Downloads/test_image.jpg

# 例3: 複数の画像を一度に追加
xcrun simctl addphoto booted ~/Desktop/photo1.jpg ~/Desktop/photo2.jpg ~/Desktop/photo3.jpg

# 例4: 絶対パスで指定（パス名をコピーした場合）
xcrun simctl addphoto booted "/Users/ken/Pictures/My Photos/person.jpg"
```

### トラブルシューティング

#### エラー: "No devices are booted"
- シミュレータが起動していない可能性があります
- Xcodeでアプリを実行してシミュレータを起動してください

#### エラー: "No such file or directory"
- 画像ファイルのパスが間違っています
- パスにスペースが含まれている場合は、ダブルクォートで囲んでください
  ```bash
  xcrun simctl addphoto booted "/Users/ken/My Photos/person.jpg"
  ```

#### 画像が表示されない
- シミュレータの「写真」アプリを一度閉じて再度開いてください
- アプリを再起動してください

## 🖼️ 方法4: アセットに画像を追加してテスト

### 手順

1. **Xcodeでプロジェクトを開く**

2. **画像をアセットに追加**
   - プロジェクトナビゲーターで `Assets.xcassets` を開く
   - 右クリック → 「New Image Set」
   - 画像セットに名前を付ける（例: `test_person`）
   - 画像ファイルをドラッグ&ドロップ

3. **コードを一時的に変更してテスト**
   ```swift
   // ContentView.swift の body 内に一時的に追加
   .onAppear {
       // アセットから画像を読み込んで設定
       if let testImage = UIImage(named: "test_person") {
           selectedImage = testImage
       }
   }
   ```

4. **テスト後は削除**
   - テストが終わったら、追加したコードを削除

2. MacのFinderから画像をドラッグ&ドロップ

**これが最も簡単で直感的です！**

## 📝 テスト用画像の準備

### 推奨画像

- ✅ **人物がはっきり写っている写真**
  - 全身または上半身が写っている
  - 人物が画面の中央付近
  - 背景と人物のコントラストがはっきりしている

- ✅ **明るく鮮明な写真**
  - 適度な明るさ
  - 焦点が合っている
  - 解像度が十分（最低640x640ピクセル推奨）

### 非推奨画像

- ❌ 人物が写っていない写真
- ❌ 人物が非常に小さい写真
- ❌ 人物がぼやけている写真
- ❌ 極端に暗い/明るい写真

---

## 🔍 トラブルシューティング

### 画像が表示されない

1. **フォトアプリを再起動**
   - シミュレータでフォトアプリを閉じて再度開く

2. **アプリを再起動**
   - Xcodeでアプリを再実行

3. **画像形式を確認**
   - JPEGまたはPNG形式であることを確認

### 画像が選択できない

1. **権限を確認**
   - 設定アプリ → プライバシーとセキュリティ → 写真
   - アプリに写真へのアクセス許可があるか確認

2. **シミュレータを再起動**
   - シミュレータを完全に終了して再起動

## 💡 便利なTips

### 複数の画像を一度に追加

```bash
# コマンドラインで複数画像を追加
xcrun simctl addphoto booted \
  ~/Pictures/person1.jpg \
  ~/Pictures/person2.jpg \
  ~/Pictures/person3.jpg
```

### シミュレータのフォトライブラリをクリア

```bash
# すべての写真を削除
xcrun simctl erase booted
```

⚠️ 注意: これによりシミュレータのすべてのデータが削除されます

### 画像のパスを確認

```bash
# シミュレータのフォトライブラリのパスを確認
xcrun simctl get_app_container booted com.apple.Photos
```
