# App Store 用スクリーンショット・プレビュー作成ガイド

iOS アプリを App Store に登録する際に必要な**スクリーンショット**と、任意の**アプリプレビュー（動画）**の作成方法をまとめています。

---

## 1. 必須：スクリーンショット

- **枚数**: 1〜10 枚（必須）
- **形式**: `.jpeg` / `.jpg` / `.png`

### stamp_creator で必要なサイズ

本アプリは **iPhone と iPad 両対応**（`TARGETED_DEVICE_FAMILY = "1,2"`）のため、**iPhone 用**と **iPad 用**の両方が必要です。

#### iPhone 用（いずれか必須）

| ディスプレイ | ピクセル（縦向き） | 推奨シミュレータ |
|-------------|-------------------|------------------|
| **6.9インチ** | 1320 x 2868 または 1290 x 2796 | iPhone 16 Pro Max, iPhone 15 Pro Max など |
| **6.5インチ** | 1242 x 2688 | iPhone 14 Pro Max, iPhone 13 Pro Max など |

- 6.9 インチ用を用意すれば、多くの iPhone サイズで適切に表示されます。
- 6.9 インチを用意しない場合は、**6.5 インチ用が必須**です。

#### iPad 用（iPad でアプリを動かす場合は必須）

| ディスプレイ | ピクセル（縦向き） | 推奨シミュレータ |
|-------------|-------------------|------------------|
| **13インチ** | 2064 x 2752 | iPad Pro 13-inch (M4) など |

---

## 2. シミュレータでスクリーンショットを取得する

### 手順

1. **Xcode** で `stamp_creator` を開く。
2. 上部のデバイス選択で、必要なサイズのシミュレータを選ぶ：
   - **iPhone**: `iPhone 16 Pro Max` または `iPhone 15 Pro Max`（6.9 インチ相当）
   - **iPad**: `iPad Pro 13-inch (M4)` など
3. **拡大率を 100% にする**: `⌘1`（重要：拡大率で画像サイズが変わる）
4. アプリを起動し、撮りたい画面で **`⌘S`**（または メニュー **File → Save Screen**）
5. **デスクトップ**に `Simulator Screen Shot 日付 時刻.png` として保存される。

### シミュレータの拡大率

| ショートカット | 拡大率 | 備考 |
|---------------|--------|------|
| `⌘1` | 100% | **デバイス解像度相当で撮影** → そのまま App Store 用に使える |
| `⌘2` | 75% | 画像が小さくなる |
| `⌘3` | 50% | 画像が小さくなる |

App Store 用には **`⌘1`（100%）** で撮るのが基本です。

### 実機で撮る場合

- 実機でスクリーンショット（サイドボタン + 音量上）を撮り、Mac に AirDrop や写真同期で取り込む。
- 実機の解像度が App Store の規定サイズと一致しない場合、画像編集でリサイズが必要です。

---

## 3. サイズが合わない場合のリサイズ

シミュレータの解像度が規定と微妙に違う場合や、実機から取り込んだ画像は、以下のような方法でリサイズできます。

### 方法 A: `sips`（macOS 標準）

```bash
# 例: 1290x2796 にリサイズ
sips -z 2796 1290 入力.png --out 出力.png
```

### 方法 B: ImageMagick

```bash
convert 入力.png -resize 1290x2796! 出力.png
```

### 方法 C: プレビュー / 写真 / Photoshop など

- 画像を開き、「大きさを変更」などで幅・高さを指定。

**注意**: アスペクト比を変えると伸びたり潰れたりするため、元の縦横比に近いサイズに合わせるか、必要に応じて余白で調整してください。

## 4. 任意：アプリプレビュー（動画）

スクリーンショットの代わりに、または併用して**動画（App Preview）**を載せられます。**任意**です。

### 主な仕様

| 項目 | 仕様 |
|------|------|
| **長さ** | 15〜30 秒 |
| **形式** | `.mov` / `.m4v` / `.mp4`（H.264 または ProRes 422 HQ） |
| **最大ファイルサイズ** | 500 MB |
| **オーディオ** | **ステレオ必須**（無音のトラックでも可。ないと「オーディオが破損しています」になる） |

### 解像度（代表）

| デバイス | 承諾解像度（縦向き） |
|----------|---------------------|
| iPhone 6.9 / 6.5 インチなど | 886 x 1920 |
| iPad 13 / 12.9 インチなど | 1200 x 1600 |

### 作り方の例

1. **QuickTime Player** でシミュレータ画面を録画（ファイル → 新規画面収録）
2. **iMovie** の「新規 App プレビュー」で長さ・解像度を整えて書き出し
3. 或者: **ffmpeg** で 15〜30 秒にトリムし、無音のステレオトラックを追加してエクスポート

音声が無いとエラーになるため、**無音のステレオトラック**を必ず含めてください。

---

## 5. デザインのポイント（App Store の慣行）

- **1 枚目**: インパクトのある画面やキャッチコピーで目を引く。
- **最初の 3 枚**: 多くはここまでしか見ないため、重要な機能・メッセージを集中させる。
- **1 枚あたり**: 伝える情報は 1 つ、多くて 2 つまで。
- **スクリーンそのままでも可**: 自作の図やテキストを載せた画像も OK。アプリの UI をそのまま見せても問題ありません。

---

## 6. App Store Connect へのアップロード

1. [App Store Connect](https://appstoreconnect.apple.com/) にログイン
2. **マイ App** → 対象アプリ → **App Store** タブ
3. 左の **「App Store」** や **「iOS」** の下にある **「スクリーンショット」** / **「App プレビュー」** の枠へドラッグ＆ドロップ、または「+」で追加
4. デバイス（6.9 インチ iPhone / 6.5 インチ iPhone / 13 インチ iPad など）ごとに、該当する画像・動画を割り当て

サイズが合っていると、そのまま受け付けられます。規定外の場合はエラーや注意が出るので、表示に従ってリサイズしてください。
