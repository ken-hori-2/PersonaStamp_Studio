# シミュレータでの制限について

## ⚠️ 重要な制限事項

**Vision Frameworkの人物セグメンテーション（`VNGeneratePersonSegmentationRequest`）は、シミュレータでは動作しない場合があります。**

### エラーの原因

- **Neural Engineが利用できない**: シミュレータにはNeural Engineが存在しないため、Vision Frameworkの一部の機能が動作しません
- **推論コンテキストが作成できない**: 「Could not create inference context」エラーが発生します

### 発生するエラー

```
⚠️ [DEBUG] Vision エラー発生: Could not create inference context
⚠️ [DEBUG] エラードメイン: com.apple.Vision
⚠️ [DEBUG] エラーコード: 9
```

## ✅ 解決方法

### 方法1: 実機でテストする（推奨）

**最も確実な方法です。**

1. **iPhone/iPadをMacに接続**
   - USBケーブルで接続
   - デバイスで「このコンピュータを信頼する」をタップ

2. **Xcodeで実機を選択**
   - Xcodeの上部ツールバーで、デバイス選択メニューから接続したデバイスを選択

3. **アプリを実行**
   - `Cmd + R` または ▶️ ボタンをクリック
   - 初回実行時、デバイスで「開発者を信頼」する設定が必要な場合があります
     - 設定 → 一般 → VPNとデバイス管理 → 開発者アプリ → 信頼

4. **動作確認**
   - 実機ではNeural Engineが利用できるため、正常に動作します

### 方法2: iOSバージョンを確認

- **iOS 15.0以上が必要**: Vision Frameworkの人物セグメンテーションはiOS 15.0以降で利用可能
- シミュレータのiOSバージョンを確認してください

### 方法3: 別のシミュレータを試す

- より新しいiOSバージョンのシミュレータを試す
- iPhone 15 Pro、iPhone 16 Proなど、最新のデバイスシミュレータを使用

## 🔍 確認事項

### 現在の設定

- **Quality Level**: `.fast`（シミュレータでも動作するように設定済み）
- **画像サイズ**: 最大1024px（処理を軽量化）
- **iOS Deployment Target**: iOS 15.0以上

### それでも動作しない場合

**実機でのテストが必須です。**

シミュレータでは、以下の機能が制限される場合があります：
- Neural Engineを使用するVision Frameworkの機能
- 一部のCore MLモデル
- カメラ機能（一部）

## 📝 まとめ

**結論**: Vision Frameworkの人物セグメンテーションは、**実機でのテストが必要**です。

シミュレータでは動作しない可能性が高いため、実機（iPhone/iPad）でテストしてください。実機では正常に動作します。

---

## 🚀 実機でのテスト手順（再掲）

1. iPhone/iPadをMacに接続
2. Xcodeで実機を選択
3. アプリを実行（`Cmd + R`）
4. 「背景を除去」ボタンをタップ
5. 正常に動作することを確認

実機では、Neural Engineが利用できるため、高精度な背景除去が可能です！
