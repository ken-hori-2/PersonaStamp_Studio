## 🚀 実行手順

### 1. Xcodeでプロジェクトを開く

```bash

cd /Users/ken/workdir/startup/portfolio_ws/PersonaStamp_Studio/create_stamp/mobile/stamp_creator

# Xcodeでプロジェクトを開く

```

または、Finderで `stamp_creator.xcodeproj` をダブルクリックして開く

### 2. ビルド設定の確認

1. Xcodeの左側のプロジェクトナビゲーターで `stamp_creator` プロジェクトを選択
2. ターゲット `stamp_creator` を選択
3. **Signing & Capabilities** タブを開く
4. **Team** が正しく設定されていることを確認（自動署名が有効になっているはず）

### 3. 実行方法

#### オプションA: iOSシミュレータで実行

1. Xcodeの上部ツールバーで、デバイス選択メニューから **iPhone 15 Pro** などのシミュレータを選択
2. **▶️ Run** ボタン（または `Cmd + R`）をクリック
3. シミュレータが起動し、アプリが表示されます

**注意**: シミュレータではカメラ機能は使用できませんが、フォトライブラリから画像を選択して背景除去は可能です。

**シミュレータで画像を追加する方法（推奨: コマンドライン）:**

1. **ターミナルを開く**（`Cmd + Space` → 「ターミナル」）

2. **以下のコマンドを実行**（画像のパスを指定）
   ```bash
   xcrun simctl addphoto booted ~/Desktop/my_photo.jpg
   ```
   - `~/Desktop/my_photo.jpg` の部分を、実際の画像ファイルのパスに置き換えてください
   - パスにスペースが含まれる場合は、ダブルクォートで囲んでください
     ```bash
     xcrun simctl addphoto booted "/Users/ken/My Photos/person.jpg"
     ```

3. **確認**
   - シミュレータで「写真」アプリを開いて、画像が追加されているか確認

4. **アプリで使用**
   - アプリに戻り、「写真を選ぶ」ボタンから選択

**簡単なスクリプトも用意しています:**
```bash
./Add_Images_Script.sh ~/Desktop/my_photo.jpg
```

詳細は `シミュレータで画像をテストする方法.md` を参照してください。

#### オプションB: 実機（iPhone/iPad）で実行

1. iPhone/iPadをMacにUSBケーブルで接続
2. デバイスで「このコンピュータを信頼する」をタップ
3. Xcodeのデバイス選択メニューから接続したデバイスを選択
4. **▶️ Run** ボタン（または `Cmd + R`）をクリック
5. 初回実行時、デバイスで「開発者を信頼」する設定が必要な場合があります
   - 設定 → 一般 → VPNとデバイス管理 → 開発者アプリ → 信頼

### 4. アプリの使用方法

1. **画像を選択**
   - 「写真を選ぶ」ボタン: フォトライブラリから画像を選択
   - 「カメラ」ボタン: カメラで撮影（実機のみ）

2. **背景除去**
   - 画像を選択後、「背景を除去」ボタンをタップ
   - 処理中は「処理中...」と表示されます（数秒かかります）
   - 処理完了後、背景が透明になった画像が表示されます

3. **保存・共有**
   - 「保存」ボタン: 写真ライブラリに透過PNGとして保存
   - 「共有」ボタン: 他のアプリに共有（メール、メッセージなど）

## ⚠️ 注意事項

### 人物検出について

- このアプリは **Vision Frameworkの人物セグメンテーション** を使用しています
- **人物が写っている画像** でないと背景除去が正しく動作しません
- 人物以外の被写体（動物、物体など）には対応していません

### 推奨画像

- ✅ 人物がはっきり写っている写真
- ✅ 背景と人物のコントラストがはっきりしている写真
- ❌ 人物が写っていない写真（背景除去できません）
- ❌ 人物が非常に小さい写真（検出できない可能性があります）

### トラブルシューティング

#### エラー: "人物が検出されませんでした"
- 画像に人物が写っているか確認してください
- より明るい、コントラストの高い画像を試してください

#### エラー: カメラが起動しない
- 実機で実行しているか確認してください（シミュレータではカメラは使用できません）
- 設定アプリで、アプリのカメラへのアクセス許可を確認してください

#### エラー: 写真ライブラリにアクセスできない
- 初回実行時、写真ライブラリへのアクセス許可を求められます
- 「許可」を選択してください
- 設定アプリで、アプリの写真へのアクセス許可を確認してください

#### ビルドエラーが発生する場合
- Xcodeを再起動してみてください
- Product → Clean Build Folder（`Shift + Cmd + K`）を実行してから再度ビルド
- プロジェクトの設定で、iOS Deployment Targetが適切に設定されているか確認

## 📝 技術的な詳細

### 使用しているAPI

- **Vision Framework**: `VNGeneratePersonSegmentationRequest`
  - 人物を検出し、マスク（グレースケール画像）を生成
  - マスクの白い部分が人物、黒い部分が背景

### 処理フロー

1. UIImage → CVPixelBuffer に変換
2. Vision Frameworkで人物セグメンテーションを実行
3. マスク（CVPixelBuffer）を取得
4. マスクを元画像のサイズにリサイズ
5. マスクの値（0-255）をアルファチャンネルとして適用
6. 透過PNG画像を生成
