# UI文言変更のまとめ

このドキュメントは、stamp_creatorアプリのUI文言を統一・改善するために実施した変更の記録です。

---

## 変更の目的

1. **ワークフローの明確化**: スタンプ作成の流れ（背景除去→ベース作成→編集→音声スタンプ）を明確にする
2. **用語の統一**: 英語では「Sticker」、日本語では「スタンプ」に統一
3. **スタイリッシュな表現**: 「Compose」など、洗練された用語の採用
4. **ユーザビリティ**: 一般ユーザーにも分かりやすい表現（「TTS」→「音声」など）

---

## 1. タブ名の変更

| タブ | 変更前（英語） | 変更後（英語） | 変更前（日本語） | 変更後（日本語） |
|------|--------------|--------------|----------------|----------------|
| **背景除去** | Remove BG | Remove BG | 背景除去 | 背景除去 |
| **ベース作成** | Create Base | **Compose** | ベース作成 | **構成** |
| **スタンプ編集** | Edit | **Edit Sticker** | 編集 | **スタンプ編集** |
| **音声スタンプ** | TTS Sticker | **Audio Sticker** | TTSスタンプ | **音声スタンプ** |

### 変更理由
- **Compose**: スタイリッシュで洗練された表現。「構成する」という創造的なニュアンス
- **Edit Sticker**: 機能を明確化（スタンプ編集であることを明示）
- **Audio Sticker**: 一般ユーザーにも分かりやすい（「TTS」は技術用語）

- 「Create Audio Sticker」: 動画スタンプ作成であることを明示

| 機能 | 変更前（英語） | 変更後（英語） | 変更前（日本語） | 変更後（日本語） |

- ボタン名は短く、シンプルに統一

## 6. 主な変更のポイント

### 英語名の統一
- ✅ **「TTS」→「Audio」**: 一般ユーザーにも分かりやすい表現に統一
- ✅ **「Create Base」→「Compose」**: スタイリッシュで洗練された表現に変更
- ✅ **「Edit」→「Edit Sticker」**: 機能を明確化
- ✅ **「Sticker」に統一**: 「Stamp」ではなく「Sticker」を使用

### 日本語名の統一
- ✅ **「TTS」→「音声」**: 一般ユーザーにも分かりやすい表現に統一
- ✅ **「合成」→「構成」**: 「Compose」のニュアンスを反映した洗練された表現
- ✅ **「画像編集」→「スタンプ編集」**: ワークフローに合わせて明確化
- ✅ **ボタン名の統一**: 「構成」など、シンプルで統一された表現

### タブ名とナビゲーションタイトルの関係
- ✅ **タブ名は短く、ナビゲーションタイトルは詳細に**: 統一されたパターン
  - 例: 「Compose」→「Compose Base」/「構成」→「ベース構成」

### 説明文とボタン名の統一
- ✅ **説明文内のボタン名表記を実際のボタン名と一致**: ユーザーの混乱を防止
  - 例: 「構成」で最終画像を作成（ボタン名「構成」と一致）

---

## 7. 最終的な統一性

すべてのタブが「スタンプ作成」のワークフローに統一されました：

1. **背景除去** - スタンプの素材準備
2. **構成** - スタンプのベース画像作成（Compose）
3. **スタンプ編集** - スタンプ画像に手描き編集
4. **音声スタンプ** - 動画スタンプ作成

### 英語と日本語の対応表

| 英語 | 日本語 | 用途 |
|------|--------|------|
| Compose | 構成 | タブ名・ボタン名 |
| Compose Base | ベース構成 | ナビゲーションタイトル |
| Composing... | 構成中... | 処理中メッセージ |
| Edit Sticker | スタンプ編集 | タブ名・ナビゲーションタイトル |
| Audio Sticker | 音声スタンプ | タブ名 |
| Create Audio Sticker | 音声スタンプ作成 | ナビゲーションタイトル |
| Generate Audio | 音声生成 | ボタン名 |
| Save | 保存 | ボタン名（全タブ統一） |

## 8. 技術的な変更

### キー名の変更
- `"Compose Base Button"` → 削除（`"Compose"`キーを使用）
- `"failed_to_generate_tts"` → `"failed_to_generate_audio"`
- `"TTS Sticker"` → `"Audio Sticker"`

### コード内の文字列変更
- `Text("TTS converts...")` → `Text("Converts...")`
- `Text("Enter text for TTS...")` → `Text("Enter text for audio...")`
- `Text("Generate TTS")` → `Text("Generate Audio")`
- `String(localized: "TTS audio generated successfully")` → `String(localized: "Audio generated successfully")`
