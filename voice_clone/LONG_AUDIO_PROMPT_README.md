# 長い音声ファイル（60秒など）からプロンプトを作成する方法

## 概要

VALL-E-Xのプロンプトは最大15秒までという制限がありますが、60秒などの長い音声ファイルから最適なセグメントを自動選択してプロンプトを作成するツールを提供しています。

## 使用方法

### 基本的な使い方

```bash
python create_prompt_from_long_audio.py vocals.wav --name vocals_long
```

### オプション

- `--name`: プロンプト名（デフォルト: vocals）
- `--segment-length`: セグメントの長さ（秒、最大15秒、デフォルト: 10.0）
- `--method`: セグメント選択方法
  - `energy`: エネルギーが最も高いセグメント（推奨）
  - `middle`: 中央のセグメント
  - `first`: 最初のセグメント
  - `last`: 最後のセグメント
- `--transcript`: 転写テキスト（省略可、Whisperで自動生成）
- `--multiple`: 複数のプロンプトを作成（各セグメントから）
- `--max-prompts`: 作成するプロンプトの最大数（--multiple使用時）

### 例

#### 1. エネルギーが最も高いセグメントを自動選択

```bash
python create_prompt_from_long_audio.py vocals.wav \
    --name vocals_best \
    --segment-length 10.0 \
    --method energy
```

#### 2. 複数のプロンプトを作成

```bash
python create_prompt_from_long_audio.py vocals.wav \
    --name vocals \
    --segment-length 10.0 \
    --multiple \
    --max-prompts 3
```

#### 3. 転写テキストを指定

```bash
python create_prompt_from_long_audio.py vocals.wav \
    --name vocals \
    --transcript "転写テキストをここに入力"
```

## 動作の流れ

1. **音声の分割**: 長い音声ファイルを指定した長さ（デフォルト10秒）のセグメントに分割
2. **セグメントの選択**: 指定した方法（デフォルト: energy）で最適なセグメントを選択
3. **プロンプトの作成**: 選択されたセグメントからプロンプトを作成

## 注意事項

- プロンプトの長さは最大15秒までです
- プロンプト+生成音声の合計は22秒以内が推奨です
- 60秒の音声は約6個のセグメント（10秒ずつ）に分割されます
- エネルギー分析により、最も音声が明確なセグメントが自動選択されます

## トラブルシューティング

### エラー: "音声ファイルが見つかりません"

絶対パスを使用するか、現在のディレクトリから相対パスを正しく指定してください。

### エラー: インポートエラー

vallexディレクトリが正しく配置されているか確認してください。

## 技術的な詳細

- 音声は10秒のセグメントに分割されます
- 各セグメントのエネルギー（音量の平均）を計算
- エネルギーが最も高いセグメントが選択されます
- 選択されたセグメントからプロンプト（.npzファイル）が作成されます
