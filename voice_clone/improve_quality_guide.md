## 1. プロンプト音声の品質向上

### ✅ 推奨事項

#### 音声の長さ
- **最適**: 5-10秒
- **最小**: 3秒
- **最大**: 15秒（制限）
- **理由**: より長いプロンプトはより多くの音素情報を含み、精度が向上します

#### 音声の品質
- ✅ **クリアな音声**: ノイズが少ない
- ✅ **一貫した音量**: 音量の変動が少ない
- ✅ **自然な話し方**: 感情やトーンが明確
- ✅ **多様な音素**: 様々な音を含む（母音、子音、アクセントなど）
- ❌ **避けるべき**: 背景ノイズ、エコー、歪み、音量の急激な変化

#### 音声の内容
- 多様な音素を含む文章を選ぶ
- 感情やトーンが明確な音声
- 自然な話し方（早口すぎない、遅すぎない）

## 2. 転写テキストの精度向上

### 方法1: より高精度なWhisperモデルを使用

現在は`medium`モデルを使用していますが、より大きなモデルを使用すると精度が向上します：

```python
# large-v2モデルを使用（より高精度だが遅い）
whisper_model = whisper.load_model("large-v2", download_root="./whisper")
```

### 方法2: 手動で転写テキストを提供

Whisperの自動転写よりも、手動で正確な転写テキストを提供する方が精度が向上します：

```python
make_prompt(
    name="vocals",
    audio_prompt_path="vocals_10sec.wav",
    transcript="正確な転写テキストをここに入力"
)
```

### 方法3: 転写テキストの検証と修正

Whisperで生成された転写テキストを確認し、誤りがあれば修正します。

## 3. 生成パラメータの調整

### Temperature（温度パラメータ）

現在: `temperature=1.0`

- **低い値（0.7-0.9）**: より一貫性があり、予測可能な出力
- **高い値（1.1-1.3）**: より多様性があり、自然な出力
- **推奨**: 0.8-1.0（音声クローンの場合）

### Top-k

現在: `top_k=-100`（無制限）

- **低い値（10-50）**: より保守的で一貫性のある出力
- **高い値（100-200）**: より多様性のある出力
- **推奨**: 50-100（バランスの取れた出力）

### 実装例

```python
# カスタムパラメータで生成
audio_array = generate_audio(
    text="テキスト",
    prompt="vocals",
    language="ja",
    temperature=0.8,  # より一貫性のある出力
    top_k=50          # より保守的なサンプリング
)
```

## 4. 音声前処理の改善

### ノイズ除去

音声ファイルにノイズがある場合、前処理でノイズを除去します：

```python
import noisereduce as nr
import soundfile as sf

# 音声を読み込み
audio, sr = sf.read("vocals.wav")

# ノイズを除去
reduced_noise = nr.reduce_noise(y=audio, sr=sr)

# 保存
sf.write("vocals_cleaned.wav", reduced_noise, sr)
```

### 正規化

音量を正規化して一貫性を保ちます：

```python
import torchaudio
import torch

wav, sr = torchaudio.load("vocals.wav")

# 正規化（最大振幅を1.0に）
if wav.abs().max() > 1:
    wav = wav / wav.abs().max()

# モノラルに変換（ステレオの場合）
if wav.size(0) == 2:
    wav = wav.mean(0, keepdim=True)

torchaudio.save("vocals_processed.wav", wav, sr)
```

### 複数のプロンプトを試す

### プロンプトの選択基準

2. **多様性**: 様々な音素を含む

4. **一貫性**: 話し方が一貫している

## ⚠️ 注意事項

1. **プロンプトの長さ**: 15秒を超えるとエラーになります
2. **生成音声の長さ**: プロンプト+生成音声の合計が22秒以内が推奨
3. **言語の一致**: プロンプトと生成テキストの言語が一致している方が精度が高い
4. **計算リソース**: より大きなWhisperモデルは時間とメモリを多く使用します

## 🔧 トラブルシューティング

### 問題: 生成音声が不自然
- **解決策**: Temperatureを下げる（0.7-0.9）、Top-kを下げる（30-50）

### 問題: 音声が元の声と似ていない
- **解決策**: より長いプロンプト（8-10秒）を使用、転写テキストの精度を確認

### 問題: ノイズが多い
- **解決策**: プロンプト音声のノイズ除去、正規化を実施

### 問題: 感情やトーンが再現されない
- **解決策**: 感情が明確なプロンプト音声を選択、プロンプトの長さを増やす
