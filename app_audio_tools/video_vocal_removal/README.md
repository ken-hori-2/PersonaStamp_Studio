# MOVファイルから人の声を削除するツール

MOVファイルから人の声（ボーカル）を削除し、伴奏のみを含む動画ファイルを生成するツールです。

## 📋 機能概要

このツールは以下の処理を行います：

1. **音声抽出**: MOVファイルから音声トラックを抽出
2. **音源分離**: Demucsを使用してボーカルと伴奏を分離
3. **音声差し替え**: 元のMOVファイルの音声を伴奏のみに差し替え

## 🚀 セットアップ

### 必要なツール

以下のツールがインストールされている必要があります：

1. **ffmpeg**（動画・音声処理）
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: [ffmpeg公式サイト](https://ffmpeg.org/download.html)からダウンロード

2. **demucs**（音源分離）
   ```bash
   pip install demucs
   ```

### インストール確認

スクリプト実行時に自動的にツールの確認が行われます。すべてのツールが利用可能な場合のみ処理が開始されます。

## 💻 使い方

### 基本的な使い方

```bash
cd app_audio_tools/video_vocal_removal
python remove_vocals_from_mov.py <MOVファイル名>
```

### 使用例

```bash
# 現在のディレクトリのMOVファイルを処理
python remove_vocals_from_mov.py wefunk_2025.MOV

# パスを指定して処理
python remove_vocals_from_mov.py /path/to/video.mov
```

## 📁 出力ファイル

処理が完了すると、以下のファイルが生成されます：

- **出力ファイル**: `<元のファイル名>_no_vocals.MOV`
  - 例: `wefunk_2025.MOV` → `wefunk_2025_no_vocals.MOV`
- **元のファイル**: そのまま保持されます（上書きされません）

### 一時ファイル

処理中に以下の一時ファイルが生成されますが、処理完了後に自動的に削除されます：

- `<ファイル名>_temp_audio.wav`: 抽出された音声ファイル

### 分離結果の保存

音源分離の結果（ボーカルと伴奏）は `separated_temp/` ディレクトリに保存されます。デバッグや確認用に保持されています。

## 🔄 処理の流れ

1. **ツールの確認**
   - ffmpegとdemucsが利用可能か確認

2. **音声抽出**（ステップ 1/3）
   - MOVファイルから音声をWAV形式で抽出
   - サンプリングレート: 44.1kHz、ステレオ

3. **音源分離**（ステップ 2/3）
   - Demucsを使用してボーカルと伴奏を分離
   - モデル: `htdemucs`（デフォルト）
   - 初回実行時はモデルのダウンロードで数分かかります

4. **音声差し替え**（ステップ 3/3）
   - 元のMOVファイルの音声トラックを伴奏に差し替え
   - 動画は再エンコードせず、音声のみを差し替え（高速）

## ⚙️ カスタマイズ

### 分離モデルの変更

デフォルトでは `htdemucs` モデルが使用されます。他のモデルを使用したい場合は、スクリプト内の `separate_vocals` 関数呼び出し部分を編集してください：

```python
separated = separate_vocals(str(temp_audio), str(separated_dir), model='htdemucs_ft')
```

利用可能なモデル：
- `htdemucs`: 最高品質（推奨・デフォルト）
- `htdemucs_ft`: 最高品質・fine-tuned版
- `mdx_extra`: 超高品質（処理時間長）
- `mdx_extra_q`: 超高品質・量子化版

## ⚠️ 注意事項

1. **処理時間**: 
   - ファイルサイズと長さによって処理時間が異なります
   - 初回実行時はモデルのダウンロードで数分かかります

2. **ファイルサイズ**: 
   - 出力ファイルのサイズは元のファイルとほぼ同じか、やや小さくなります
   - 音声のみが差し替えられるため、動画の品質は保持されます

3. **音声品質**: 
   - 音源分離の精度は元の音源の品質に依存します
   - 完全に人の声を除去できない場合があります

4. **対応形式**: 
   - 入力: MOV形式（その他の動画形式も対応可能）
   - 出力: MOV形式（AAC音声コーデック）

## 🐛 トラブルシューティング

### エラー: "ffmpegが見つかりません"

ffmpegがインストールされていないか、PATHに含まれていません。システムにffmpegをインストールしてください。

### エラー: "demucsが見つかりません"

demucsがインストールされていません。以下のコマンドでインストールしてください：

```bash
pip install demucs
```

### エラー: "音源分離に失敗しました"

- モデルのダウンロードに失敗している可能性があります
- インターネット接続を確認してください
- 初回実行時はモデルのダウンロードで時間がかかります

### 処理が途中で止まる

- 大きなファイルの処理には時間がかかります
- 進捗が表示されない場合は、しばらく待ってください
- エラーメッセージを確認してください
