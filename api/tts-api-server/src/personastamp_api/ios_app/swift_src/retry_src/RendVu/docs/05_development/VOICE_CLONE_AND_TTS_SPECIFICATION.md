# 音声クローン・TTS機能 設計仕様書

## 📋 概要

本ドキュメントは、音声処理、音声クローン、TTS（Text-to-Speech）機能の設計仕様を記載します。クレジット消費を最適化し、音声クローンの精度を向上させるための制限と機能を実装しています。

## 🎯 目的

1. **クレジット消費の最適化**: TTSの秒数に応じたクレジット消費を制限するため、TTSの文字数制限を実装
2. **音声クローンの精度向上**: 音源分離と無音区間削除を独立した機能として提供し、処理済み音声を再利用可能にする
3. **ユーザビリティの向上**: 録音だけでなく、ファイル選択から音声処理、音声クローンまで一貫した操作を提供
4. **機能の分離**: 音声処理を独立したタブとして提供し、各機能の責務を明確化

## 📝 機能仕様

### 1. 音声処理機能（独立タブ）

#### 1.1 概要

音源分離と無音区間削除を実行する独立した機能として提供します。Voice Cloneタブとは別のタブとして実装されています。

**目的**:
- 音声処理を独立した機能として提供
- 処理済み音声を保存・再利用可能にする
- Voice Cloneタブをシンプルに保つ

#### 1.2 機能詳細

**ファイル選択**:
- 音声ファイルを選択（WAV、MP3、M4A、FLAC、OGG対応）
- ファイル長さチェック（最大1分）

**音声処理設定**:
- 音源分離（ボーカル抽出）: ON/OFF
- 無音区間削除: ON/OFF
- 分離モデル選択:
  - `htdemucs`（推奨・デフォルト）
  - `htdemucs_ft`
  - `mdx_extra`
  - `mdx_extra_q`

**処理結果**:
- ボーカル音声（音源分離した場合）
- 処理済み音声
- 再生・保存機能

**実装ファイル**:
- `RendVu/ViewModels/AudioProcessingViewModel.swift`: 音声処理のViewModel
- `RendVu/Views/AudioProcessingView.swift`: 音声処理画面

**UI構成**:
```
音声処理タブ
├── ファイル選択ボタン
├── 選択ファイル表示
├── 処理設定
│   ├── 音源分離トグル
│   ├── 無音区間削除トグル
│   └── 分離モデル選択
├── 処理実行ボタン
└── 処理結果
    ├── ボーカル音声（再生・保存）
    └── 処理済み音声（再生・保存）
```

### 2. TTS（Text-to-Speech）機能

#### 1.1 文字数制限

**目的**: TTSの生成時間を最大5秒程度に制限し、クレジット消費を抑制する

**仕様**:
- 最大文字数: **30文字**
- 文字数カウントをUIに表示（`X/30`形式）
- 30文字を超える場合はエラーメッセージを表示
- エラーメッセージ: "テキストは最大30文字まで入力できます（現在: X文字）。TTSの時間を5秒以内に制限するためです。"

**実装ファイル**:
- `RendVu/ViewModels/TTSViewModel.swift`: `generateTTS`メソッドで文字数チェック
- `RendVu/Views/TTSView.swift`: 文字数カウント表示

**UI表示**:
```
テキスト入力
[TextEditor]
30/30  ← 文字数カウント（30文字超過時は赤色表示）
```

### 3. 音声クローン機能

#### 2.1 録音時間制限

**目的**: 音声クローンモデル生成時の録音時間を最大1分に制限

**仕様**:
- 最大録音時間: **60秒（1分）**
- 60秒到達時に自動停止
- 自動停止時にエラーメッセージを表示: "録音時間は最大1分までです。1分で自動停止しました。"
- 録音中に「最大1分まで録音できます」という警告を表示

**実装ファイル**:
- `RendVu/ViewModels/VoiceCloneViewModel.swift`: `updateRecordingTime`メソッドで自動停止処理

**UI表示**:
```
録音中: 00:45
最大1分まで録音できます  ← 警告メッセージ（オレンジ色）
```

#### 2.2 ファイル選択機能

**目的**: 録音だけでなく、既存の音声ファイルから音声クローンモデルを生成可能にする

**仕様**:
- ファイル選択ボタンを録音ボタンの横に配置
- サポートファイル形式:
  - WAV
  - MP3
  - M4A
  - FLAC
  - OGG
- 選択したファイルの長さをチェック（最大1分）
- 1分を超える場合はエラーメッセージを表示
- ファイル選択後、自動文字起こしが有効な場合は文字起こしを実行

**実装ファイル**:
- `RendVu/ViewModels/VoiceCloneViewModel.swift`: `selectAudioFile`, `handleSelectedAudioFile`メソッド
- `RendVu/Views/VoiceCloneView.swift`: ファイル選択UIと`fileImporter`モディファイア

**UI表示**:
```
[録音] [ファイル]  ← 2つのボタンを横並び

ファイルが選択されました  ← ファイル選択後の確認メッセージ
```

#### 3.3 音声処理との連携

**設計方針**: 音声処理は独立したタブとして提供し、Voice Cloneタブからは削除

**推奨ワークフロー**:
1. **音声処理タブ**で音声ファイルを処理
   - ファイル選択
   - 音源分離・無音区間削除を実行
   - 処理済み音声を保存
2. **Voice Cloneタブ**で処理済み音声を使用
   - 録音またはファイル選択（処理済み音声ファイルを選択可能）
   - モデル名を入力
   - Voice Cloningを実行

**メリット**:
- Voice Cloneタブがシンプルになる
- 処理済み音声を再利用可能
- 音声処理を独立した機能として提供

## 🔧 技術実装詳細

### 3.1 ファイル構造

```
RendVu/
├── ViewModels/
│   ├── TTSViewModel.swift              # TTS機能のViewModel
│   ├── VoiceCloneViewModel.swift       # 音声クローン機能のViewModel
│   └── AudioProcessingViewModel.swift  # 音声処理機能のViewModel
├── Views/
│   ├── TTSView.swift                   # TTS画面
│   ├── VoiceCloneView.swift            # 音声クローン画面
│   ├── AudioProcessingView.swift       # 音声処理画面
│   └── MainTabView.swift              # メインタブビュー
└── Services/
    └── APIClient.swift                 # API通信クライアント
```

### 3.2 主要なメソッド

#### TTSViewModel

- `generateTTS(authManager:)`: TTS生成（文字数チェック含む）

#### VoiceCloneViewModel

- `startRecording()`: 録音開始（既存ファイル選択をクリア）
- `stopRecording()`: 録音停止（自動文字起こし実行）
- `updateRecordingTime()`: 録音時間更新（1分で自動停止）
- `selectAudioFile()`: ファイル選択ダイアログ表示
- `handleSelectedAudioFile(_:)`: 選択ファイル処理（長さチェック、文字起こし）
- `cloneVoice(authManager:)`: 音声クローン実行

#### AudioProcessingViewModel

- `selectAudioFile()`: ファイル選択ダイアログ表示
- `handleSelectedAudioFile(_:)`: 選択ファイル処理（長さチェック）
- `processAudio(authManager:)`: 音声処理実行（音源分離・無音区間削除）
- `saveProcessedAudio()`: 処理済み音声を保存
- `reset()`: 状態をリセット

#### APIClient

- `processAudio(...)`: 音声処理API呼び出し（音源分離・無音区間削除）
- `cloneVoice(...)`: 音声クローンAPI呼び出し

### 3.3 データフロー

#### TTS生成フロー

```
ユーザー入力（最大30文字）
  ↓
文字数チェック
  ↓
TTS API呼び出し
  ↓
音声再生
```

#### 音声処理フロー

```
ファイル選択
  ↓
ファイル長さチェック（最大1分）
  ↓
処理設定（音源分離・無音区間削除）
  ↓
音声処理API呼び出し
  ↓
処理済み音声取得
  ↓
再生・保存
```

#### 音声クローン生成フロー

```
録音 or ファイル選択（処理済み音声も選択可能）
  ↓
録音時間/ファイル長さチェック（最大1分）
  ↓
自動文字起こし（オプション）
  ↓
Voice Cloning API呼び出し
  ↓
モデル生成完了
```

## 📊 制限事項

### TTS機能

- **文字数制限**: 最大30文字
- **目的**: TTS生成時間を約5秒以内に制限

### 音声クローン機能

- **録音時間制限**: 最大60秒（1分）
- **ファイル長さ制限**: 最大60秒（1分）
- **目的**: クレジット消費を抑制し、モデル生成時間を短縮

## 🎨 UI/UX設計

### エラーメッセージ

- **ファイル長さ超過**: 選択時にエラーメッセージ、具体的な長さを表示

## 🔐 セキュリティ・プライバシー

- すべてのAPI呼び出しでFirebase IDトークンによる認証が必要
- 録音ファイルは処理後に自動削除
- ファイル選択時はセキュリティスコープ付きURLを使用
