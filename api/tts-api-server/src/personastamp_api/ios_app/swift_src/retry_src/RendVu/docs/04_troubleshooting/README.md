# トラブルシューティング

## 📋 概要

よくあるエラーとその解決方法に関するドキュメントです。

## 📖 ドキュメント一覧

- `authentication_errors.md` - 認証関連のエラーと解決方法
- `FIX_BUNDLE_ID_ERROR.md` - Bundle IDエラーの解決方法
- `FIX_BLACK_SCREEN.md` - 画面が黒い問題の解決方法
- `FIX_MICROPHONE_PERMISSION.md` - マイク権限の問題の解決方法

## 🚀 クイックスタート

1. エラーメッセージを確認
2. 該当するドキュメントを参照
3. 解決方法を実施
