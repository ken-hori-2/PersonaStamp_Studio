# 音源分離: Spleeter（依存関係の競合により、requirements.txtから除外）
# 
# 問題1: Python 3.13とSpleeterの互換性
#   - SpleeterはPython 3.10までしかサポートしていません
#   - Python 3.13では動作しない可能性が高いです
#
# 問題2: httpxのバージョン要件の競合（解消不可能）
#   - spleeter 2.1.0 → httpx<0.17.0 and >=0.16.1
#   - firebase-admin 7.1.0 → httpx==0.28.1
#   - fish-audio-sdk 1.1.0 → httpx>=0.27.2
#   - fish-audio-sdk 1.0.0 → httpx>=0.27.2（1.1.0と同じ）
#   これらは同時に満たすことができません
#
# 調査結果（詳細は docs/DEPENDENCY_INVESTIGATION.md を参照）:
#   - firebase-adminを6.x系にダウングレードしても、fish-audio-sdkとspleeterの間の競合は残ります
#   - fish-audio-sdk 1.0.0もhttpx>=0.27.2を要求するため、spleeterとの競合は解消できません
#   - 結論: httpxの依存関係の競合は解消不可能
#
# 解決策:
#   1. 音源分離をiOSアプリ側で実装する（最推奨）
#   2. 音源分離専用の別サービスとして分離する（Python 3.10環境で実行）
#   3. 別の軽量な音源分離ライブラリを検討する
#   4. Python 3.10にダウングレード（ただし、httpxの競合は依然として残る）
#
# 手動インストールは不可能（httpxの依存関係の競合によりインストールできません）
# spleeter==2.1.0
